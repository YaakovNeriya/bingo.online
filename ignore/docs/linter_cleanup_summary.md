# סיכום ניקוי היגיינת קוד (Linter Clean-up)

מסמך זה מסכם את עבודת ניקוי הקוד וניהול הייבואים (Imports) שבוצעה על השרת (Backend) באמצעות כלי ה-Linter.

## 1. הממצאים (Code Smells)
במהלך סריקת המערכת התגלו מספר בעיות חוזרות בהיגיינת הקוד:
* **ייבואים כפולים (F811):** פונקציות מספריות (כמו `select` ו-`func` מ-SQLAlchemy) שיובאו מספר פעמים באותו קובץ ללא סיבה.
* **ייבואים לא מנוצלים (F401):** מודלים וספריות שנטענו אל תוך הקובץ או אל תוך פונקציות (למשל `import os` או מודל `CartItem`), למרות שלא נעשה בהם שום שימוש.
* **ייבואים מקומיים (E402):** ספריות בסיס שיובאו בתוך גוף הפונקציה או באמצע הקובץ במקום בראשו, מה שגורם להאטה ולחוסר סדר.

## 2. פעולות הניקוי שבוצעו
הופעלה הפקודה האוטומטית של הלינטר `ruff --fix` על כל תיקיית השרת.
הפעולה **ניקתה בהצלחה 36 בעיות קוד** ברחבי הפרויקט:
* מחיקה אוטומטית של כל המשתנים והייבואים שלא היו בשימוש.
* מחיקת כל הכפילויות והדריסות (Redefinitions).
* הניקוי עבר בהצלחה 100% ממבחני המערכת (Pytest) ולא שבר שום פונקציונליות.

## 3. ניהול סיכונים חכם
במהלך הניקוי, הלינטר הונחה להתעלם ולא לתקן באופן אוטומטי בעיות מסוג **E402** (ייבואים בתוך פונקציות). 
פעולה זו נעשתה בכוונה תחילה כדי לשמור על הארכיטקטורה הקיימת וכדי להימנע מסכנה של **Circular Imports** (מעגליות תלויות) שעלולה לרסק את השרת בזמן ריצה.

בנוסף, הלינטר ביצע מחיקה אגרסיבית מדי לקובץ הרישום של מסד הנתונים (`app/db/base.py`) מכיוון שהמודולים שם לא בשימוש ישיר. הקובץ **שוחזר מידית למצבו המקורי** כדי להבטיח שמערכת המיגרציות תמשיך לזהות את הטבלאות.

## 4. המלצה להמשך - תצורת Linter
כדי להבטיח שה-Linter לא ימחק קבצי בסיס בעתיד ויפסיק להתריע על ייבואים פנימיים (E402), מומלץ ליישם אחת משתי השיטות הבאות:

### שיטה מהירה: הוספת `# noqa`
הוספת הערה בראש קבצים שנועדו לחשוף מודולים (כמו `base.py`):
```python
# ruff: noqa: F401
from app.db.base_class import Base
from app.domains.users.models import User
```

### השיטה המקצועית: קובץ `ruff.toml`
יצירת קובץ הגדרות בתיקיית ה-backend:
```toml
# התעלמות משגיאות של מיקום הייבוא למניעת מעגליות
extend-ignore = ["E402"]

# פטור מיוחד מקבצים שבהם הייבואים לא בשימוש ישיר
[per-file-ignores]
"app/db/base.py" = ["F401"]
"__init__.py" = ["F401"]
```
